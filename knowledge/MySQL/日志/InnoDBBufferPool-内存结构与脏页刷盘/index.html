InnoDB Buffer Pool - 内存结构与脏页刷盘

Buffer Pool 是 InnoDB 最重要的内存结构，它是 Undo、Redo、数据页、锁机制的交汇点。前面讲的 Undo 页、数据页、索引页，在没有刷盘之前，全都在 Buffer Pool 里。

一、Buffer Pool 是什么？

一句话：Buffer Pool 是内存中的一块区域，缓存磁盘上的数据页，让大部分读写操作直接在内存完成。
