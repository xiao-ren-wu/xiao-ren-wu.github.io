算法知识地图

本页用途

算法全库的总入口。当前收录14 个子主题、77 道带题解的题 + 1 个 100 题 DP 专项。 本页回答三个问题：我在知识树的哪里？相邻主题的边界在哪？考前按什么顺序刷？

数据来源是个人题解站 xiao-ren-wu.github.io 的 77 篇题解， 按本库格式重写。站点另有 203 道题的元数据，其中约 126 道暂无题解，未收录。

收录原则

只收有完整题解的题，且只做格式重写、不改结论。原解的思路、代码、复杂度都保留， 只在必要时补 一句话结论 与摘要里缺失的复杂度。每道题都归入且仅归入一个子主题。

关键结论

一、三个最值得反复确认的边界

初学者最大的浪费不是刷题少，而是在错误的分支上刷了太多题。这三组边界想清楚，能砍掉一半无效时间。

边界混淆的代价怎么一次性分清
对撞 / 同向 / 收敛双指针和滑窗的题互相套错模板记住移动方向由什么驱动：比较结果 vs 窗口是否满足 vs 答案是否在中点
DP 的四类状态维度把区间 DP 写成前缀 DP，边界条件全错看答案依赖几个下标，以及下标之间是什么关系（并列 / 前后 / 嵌套）
贪心 vs DP该用 DP 时贪心，写出来过不了样例问自己「我这一步拿最好的，之后会不会凑不出最优解？」

二、动态规划值得单独开一个专题

14 个主题里只有 DP 值得按题型分类刷题——它有 8 种状态设计，混在一起刷没有意义。 本库为此单独建了 动态规划专项，收录 100 道题分 8 批，每题含状态图、Java 代码和复杂度。

层级笔记作用

三、77 道题的难度分布

难度题数占比说明
困难 HARD2127%集中在单调栈、DP、数学与位运算、设计与数据结构
中等 MEDIUM5673%主体是数据结构类和基础算法类

这个分布意味着什么

中等题占七成说明原题的选材是偏面试实用的。这意味着：先把中等题的模板吃透，比去啃 21 道难题性价比高得多。 推荐的刷题顺序也是中等题优先、难题按主题选做。

刷题路线

阶段刷什么题量目标
一、建模板数组与双指针 → 哈希表与集合 → 链表 → 二分查找 → 滑动窗口与单调栈31把 5 个高频模板写到肌肉记忆
二、上递归二叉树 → 图与网格 → 回溯与递归16递归骨架 + 网格遍历 + 回溯撤销
三、攻 DP动态规划专项 三阶段路线（前 45 题即可覆盖主干）45DP 三件套 + 状态维度扩展
四、补尾巴排序与选择 → 贪心 → 字符串 → 数学与位运算 → 设计与数据结构21覆盖剩余套路与 Hard 题

不要按难度排序刷

正确顺序是按主题、按状态维度。DP 尤其如此——把同状态设计的题连着刷，第二题会比第一题快一半； 而把 DP 和贪心交替着刷，每题都要重新切换心智模型。详见 动态规划专项 的刷题路线。
