动态规划专项索引

本页用途

动态规划是本库里唯一一个需要按「题型」而不是按「难度」组织的算法专题。本页是 100 题的总入口： 下面 8 篇批次笔记按 DP 的八种状态设计分类，每篇收录 10~15 道题，每题都有题意、状态图、Java 代码和复杂度。 它的定位是查表和刷题路线——已经会写 DP 的人来这里找套路，不会写的人先读 动态规划索引 的「关键结论」那一节。

本页与「动态规划索引」的区别

动态规划索引 是本主题全部笔记的导航（含 9 篇单题叶子笔记）；本页是 100 题专项的路线图，只管这 8 篇批次笔记。 两者互为上下游，不重复内容。

刷题路线

DP 的学习曲线不是线性的，按下面三段走效率最高：

阶段读什么目标预计题量
一、立骨架线性 DP 与一维递推 → 背包问题把「状态定义 → 转移 → 初始化 → 顺序」这四步变成肌肉记忆1~45
二、扩维度序列 DP → 区间 DP → 树形 DP 与换根学会把状态从「一个位置」扩到「两个位置」「一个区间」「一个节点」16–30, 46–70
三、压复杂度DP 优化 → 状态压缩 DP → 数位、概率与博弈 DP处理 n 很大或状态集合很特殊的情况71–100

不要按题号顺序刷

状态压缩 DP（第 71 题）依赖集合编码的概念，而背包的「一维状态 + 循环顺序」是理解它的最好铺垫。 博弈 DP（第 89 题）则要求先有博弈论的胜负定义直觉。建议严格按上面的三阶段顺序。
