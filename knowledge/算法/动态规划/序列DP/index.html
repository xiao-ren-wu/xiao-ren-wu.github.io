序列 DP（LIS / LCS / 编辑距离 / 回文）

本页用途

状态从「一维位置」扩到「两个位置」，即dp[i][j]。这一批是 DP 里题型最集中、也最能看出状态定义水平的部分：子序列不连续、子串连续、两个字符串对齐——三种边界条件对应三套写法。

题号与频率

收录 第 16~30 题，面试命中率 ★★★★★。题目编号沿用 动态规划专项 的全局编号。

与本库已有笔记的关系

本批的 编辑距离、通配符匹配、最长回文子串 在本库已有独立笔记。另可对照 不同的子序列 II（计数 DP 的去重技巧）。

16. 最长递增子序列 LIS（LC 300）

思路：dp[i] = 以 i 结尾的 LIS 长度，向前找所有 nums[j] < nums[i] 的 j 取最大。可用二分贪心优化到 O(n log n)。

复杂度：O(n log n) / O(n)。

17. 最长递增子序列的个数（LC 673）

思路：dp[i] 长度 + cnt[i] 方案数。转移时 dp[j]+1 > dp[i] 则覆盖，== 则累加。

复杂度：O(n²) / O(n)。

18. 俄罗斯套娃信封（LC 354）

思路：按宽度升序、宽度相同时高度降序，然后对高度求 LIS（严格递增）。

复杂度：O(n log n) / O(n)。

19. 最长连续递增序列（LC 674）

复杂度：O(n) / O(1)。

20. 最长公共子序列 LCS（LC 1143）

思路：dp[i][j] = A 前 i、B 前 j 的 LCS。

复杂度：O(mn) / O(n)。

21. 最长公共子串

思路：与 LCS 不同，子串必须连续。dp[i][j] = 以 A[i-1]、B[j-1] 结尾的公共子串长度，不等时归 0。

复杂度：O(mn) / O(n)。

22. 编辑距离（LC 72）

本题在本库已有独立笔记

见 编辑距离，含更完整的图解与关键细节。

思路：增、删、改三种操作。dp[i][j] = word1 前 i 变成 word2 前 j 的最少操作。

复杂度：O(mn) / O(mn)（可压缩为 O(n)）。

23. 两个字符串的删除操作（LC 583）

思路：答案 = m + n - 2 * LCS(a, b)。

复杂度：O(mn) / O(n)。

24. 不同的子序列（LC 115）

思路：dp[i][j] = s 前 i 中出现 t 前 j 的个数。

复杂度：O(mn) / O(n)。

25. 最长回文子序列（LC 516）

思路：区间 DP。dp[i][j] = s[i..j] 的最长回文子序列长度。

复杂度：O(n²) / O(n²)。

26. 最长回文子串（LC 5）

本题在本库已有独立笔记

见 最长回文子串，含更完整的图解与关键细节。

思路：dp[i][j] = s[i..j] 是否回文；长度为 1、2 特判，转移 dp[i][j] = s[i]==s[j] && dp[i+1][j-1]。

复杂度：O(n²) / O(n²)（另有 Manacher O(n)）。

27. 回文子串计数（LC 647）

复杂度：O(n²) / O(n²)。

28. 分割回文串 II（LC 132）

思路：先用上一题求回文矩阵，再做二次 DP：cut[i] = 前 i 个字符的最少分割数。

复杂度：O(n²) / O(n²)。

29. 最短公共超序列（LC 1092）

思路：长度 = m + n - LCS，并可用 LCS 反向构造字符串。

复杂度：O(mn) / O(mn)。

30. 通配符匹配（LC 44） / 正则匹配（LC 10）

本题在本库已有独立笔记

见 通配符匹配，含更完整的图解与关键细节。

通配符思路：? 匹配任一单字符、* 匹配任意串（含空）。

正则匹配思路：* 表示”前一字符出现 0 次或多次”。dp[i][j] 转移分 pc == s[i-1] 或 pc == '.'，以及 pc == '*' 分 dp[i][j-2]（0 次）与 dp[i-1][j]（多次）。

复杂度：均为 O(mn)。
