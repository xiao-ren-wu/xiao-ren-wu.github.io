数位 DP / 概率 DP / 博弈 DP

本页用途

三类状态带额外维度的 DP：数位 DP 的状态是 (位置, 是否贴上界)，概率 DP 的状态是 (局面, 轮次)，博弈 DP 的状态是 (局面, 先手优势)。共同点是——把「前缀信息」压进状态，用记忆化搜索写最省事。

题号与频率

收录 第 81~90 题，面试命中率 ★★★。题目编号沿用 动态规划专项 的全局编号。

82. 数字 1 的个数（LC 233）

思路：按位统计每一位为 1 的次数：(high+1)*factor 与 low 修正。

83. 至少有 1 位重复的数字（LC 1012）

思路：总数 - 无重复数位数（数位 DP）。

84. 不含连续 1 的非负整数（LC 600）

85. 抛掷硬币（LC 1230）

思路：dp[j] = 前 i 枚中 j 枚正面的概率。

86. 骑士在棋盘上的概率（LC 688）

思路：dp[i][j] 为 k 步后仍在棋盘的概率，八方向转移。

87. 新 21 点（LC 837）

思路：滑动窗口优化的概率 DP。

88. 石子游戏 II（LC 1140）

思路：dp[i][m] = 从 i 开始，可拿 [1, 2m] 个石子时的最大差值。

89. 猫和老鼠（LC 913）

题意：无向图里老鼠在 0 洞、猫在 n-1 洞，猫先手轮流移动一步，各走一步算一回合。老鼠到 0 或猫到 n-1 即分胜负。

思路：博弈 DP 的逆推（逆向拓扑）写法，比记忆化搜索好写得多——从所有已分出胜负的终止局面往回推。

记号含义
res[c][m]猫在 c、鼠在 m 时的结局：0 鼠胜 / 1 猫胜 / -1 未定
deg[c][m]这个局面的后继总数，每被确定一个就减一，减到 0 说明该局面已被完全逆推

复杂度：时间 O(n²)，空间 O(n²)。

「后继全输才输 / 全赢才赢」是同一条规则

猫回合走1 - res[...]（猫输掉所有后继才判负），鼠回合也走 1 - res[...]（老鼠赢掉所有后继才判胜）。 差别在于：猫要全部后继都输，鼠只要有一个后继能赢——所以两种情况都写成”取反 + 计数减到 0”，靠 deg 区分谁该赢。 这是博弈 DP 逆推的核心，记住这一条就够用了。
