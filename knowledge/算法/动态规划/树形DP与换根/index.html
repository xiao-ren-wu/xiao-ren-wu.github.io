树形 DP 与换根 DP

本页用途

树形 DP 的固定范式是后序遍历 + 返回多个值：每个节点向父节点返回一组状态（如 {不选, 选}），在节点处完成转移。二叉树中的最大路径和 是这套写法的入门样本，本批把它展开成完整的树上 DP 体系。

题号与频率

收录 第 59~70 题，面试命中率 ★★★★。题目编号沿用 动态规划专项 的全局编号。

与本库已有笔记的关系

换根 DP（第 70 题）是树形 DP 的进阶：两遍 DFS，第一遍求子树规模，第二遍把「根」沿边移动一次。

59. 打家劫舍 III（LC 337）

思路：每节点返回 {不偷, 偷} 两值。rob = val + left.notRob + right.notRob；notRob = max(left) + max(right)。

60. 二叉树中的最大路径和（LC 124）

思路：后序遍历，返回”以当前节点为端点向下能贡献的最大值”；全局答案是”经过当前节点左+右+自身”。

61. 二叉树的直径（LC 543）

思路同上，ans = max(L + R)，返回 1 + max(L, R)。

62. 二叉树中的最长交错路径（LC 1372）

思路：dfs(node, isLeft) 返回沿当前方向的最长交错长度。

63. 监控二叉树（LC 968）

思路：三状态：0 未覆盖、1 已覆盖无摄像头、2 有摄像头。

64. 二叉树中的最大 BST 子树（LC 333）

思路：返回 {isBST, min, max, size}。

65. 打家劫舍 III（树上变体）

见第 59 题

第 59 题已给完整实现。这里的变体只是把「相邻不能选」换成树上条件：父子之间不能同时选。

结构完全相同——每个节点返回 {不选, 选} 两个值，父节点在「选」分支里只能用子节点的「不选」值。 详见第 59 题与第 68 题（树的最大独立集是同一套转移）。

66. 叶值的最小代价生成树（LC 1130）

题意：每个内部节点的值 = 其所有孩子值之和，代价是所有内部节点值之和。给定叶值数组（已从小到大排好）， 构造二叉树使代价最小。关键性质：每两个叶值都会在某一步被合并，合并代价 = 较小的那个。

思路：树形 DP。每个节点返回 {a, b}：

返回值含义
a该子树作为最终合并根时，最小的根值
b该子树内部（不含该根自身）所有节点值之和的最小值

复杂度：时间 O(n)，空间 O(n)。

这题用贪心更快，但树形 DP 更好讲

已知叶值有序时，最优策略就是「每次合并当前最小的两个」，用小顶堆 O(n log n) 即可。上面给 DP 是因为它更能体现 「每步合并代价由较小者决定」这个结构。面试时两句话都要说。

67. 每个元音包含偶数次的最长子字符串（LC 1371，状态压缩 + 前缀）

思路：5 位掩码表示奇偶性，记录首次出现的掩码位置。

68. 树的最大独立集（模板题）

题意：在树上选若干节点，使任意两个被选节点不相邻，最大化权值和。

思路：每个节点返回 {不选, 选} 两个值，转移：

状态转移含义
dp[u][0]Σ max(dp[v][0], dp[v][1])不选 u，孩子选不选都行
dp[u][1]w[u] + Σ dp[v][0]选 u，所有孩子必须不选

复杂度：时间 O(n)，空间 O(h)（递归栈，h 为树高）。

和第 59 题（打家劫舍 III）是同一道题

打家劫舍 III 就是无权版本的最大独立集。“相邻不能选” = 独立集——记住这一个等价关系，两道题合成一道。

思路：dp[u][0] = 不选 u 的最大值，dp[u][1] = 选 u 的最大值。转移：dp[u][0] = Σ max(dp[v][0], dp[v][1])，dp[u][1] = w[u] + Σ dp[v][0]。

69. 树的最小点覆盖（模板题）

题意：选若干节点，使每条边至少有一个端点被选，最小化选中个数。

思路：同样是 {不选, 选}，但目标是最小化且转移条件相反：

状态转移含义
dp[u][0]Σ min(dp[v][0], dp[v][1])不选 u，则每条子边 (u,v) 只能靠 v 被选来覆盖
dp[u][1]1 + Σ dp[v][0]选 u，所有子边已被 u 覆盖，孩子最优是不选

复杂度：时间 O(n)，空间 O(h)。

第 63 题（监控二叉树 LC 968）不是同一道题

968 要求每个节点都被覆盖，比最小点覆盖多一条「叶子必须被选中」的约束，转移式因此不同。 见第 63 题，别直接套这里的模板。

思路：dp[u][0] = u 被覆盖且不选 u（由子节点覆盖）；dp[u][1] = 选 u。

70. 换根 DP — 树中距离之和（LC 834）

思路：两遍 DFS。第一遍求子树大小与根节点到所有点距离和；第二遍换根转移 ans[v] = ans[u] + n - 2*size[v]。
