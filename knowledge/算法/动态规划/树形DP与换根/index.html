树形 DP 与换根 DP

本页用途

树形 DP 的固定范式是后序遍历 + 返回多个值：每个节点向父节点返回一组状态（如 {不选, 选}），在节点处完成转移。二叉树中的最大路径和 是这套写法的入门样本，本批把它展开成完整的树上 DP 体系。

题号与频率

收录 第 59~70 题，面试命中率 ★★★★。题目编号沿用 动态规划专项 的全局编号。

与本库已有笔记的关系

换根 DP（第 70 题）是树形 DP 的进阶：两遍 DFS，第一遍求子树规模，第二遍把「根」沿边移动一次。

本页有一处「分类借位」，先说明

第 67 题（LC 1371 每个元音包含偶数次的最长子字符串）不是树形 DP，它是「位压缩 + 前缀」问题。 它之所以排在本页，是因为它示范了一个树形 DP 同样要回答的问题：状态怎么打包成一个可哈希的量。 其位压缩本体在 状态压缩 DP 里会再次出现（作为状压的前哨站）。

59. 打家劫舍 III（LC 337）

① 题意

给一棵二叉树，节点值 val ∈ [0, 1000]。相邻（父子）节点不能同时被”偷”，求能偷到的最大总和。

官方样例：root = [3,2,3,null,3,null,1] → 7。

与线性版 打家劫舍 的唯一区别

线性版是dp[i] = max(dp[i-1], dp[i-2] + nums[i])，只需要前一个状态。 树上版每个节点有两个孩子，所以每个节点要返回两个状态给父亲用。

② 暴力解法与瓶颈

对每个节点枚举「偷 / 不偷」，共 2^n 种组合。记忆化后能降到 O(n)，但朴素记忆化会算错：父亲想知道”我被偷了，你能不能偷”，同一个子树在”父亲被偷”和”父亲没被偷”两种语境下答案不同。

所以不能只用 Map<TreeNode, Integer> 存一个值，必须存一对值。 这是本页第一核心。

③ 状态定义

dfs(u) 返回长度为 2 的数组：

位置含义
[0]不偷 u 时，u 的整棵子树能偷到的最大值
[1]偷 u 时，u 的整棵子树能偷到的最大值

状态定义里必须带**“以 u 为根的整棵子树”**这个范围限定，否则父亲无法组合。

不偷 u：u 本身不贡献，两个孩子各自独立地选自己的最优（偷不偷都行）：

偷 u：u 贡献 val，于是两个孩子必须都不偷（父子相邻）：

“不重不漏”论证

任何一种合法方案，对u 而言必然落在”偷”或”不偷”两种情况之一，两种情况互斥且穷尽。 选定之后，孩子的可选集合被约束为”两者取优”（不偷 u）或”强制不偷”（偷 u），分别对应两个转移式。

⑥ 初始化与遍历顺序

  • 初始化：空节点返回 {0, 0}（没有节点可偷，两个状态都是 0）。这里 {0,0} 的第二项”偷空节点得 0”看似多余，但必须存在，否则 L[0] 会越界。
  • 遍历顺序：后序。必须先拿到两个孩子的返回值，才能算自己。写前序一定要先把递归结果存到变量里再用，不能边遍历边累加。

⑨ 复杂度

  • 时间 O(n)：每个节点访问一次，每次做常数次 max 与加法。

链形树会栈溢出

面试追问：

  • 「树很深会怎样？」→ 栈溢出，转迭代后序。
  • 「能不能只用一维数组？」→ 不能，父子两个状态必须成对传递（这正是树形 DP 与线性 DP 的分界）。

60. 二叉树中的最大路径和（LC 124）

① 题意

二叉树中一条路径从任意节点出发，到任意节点结束，至少含一个节点。求节点值之和的最大值。节点值可负（[-1000, 1000]）。

官方样例：root = [1,2,3] → 6（路径 2 → 1 → 3）。

两条路径是

不同的 「向下延伸的链」用来往上传值，「经过 u 的拐弯路径」用来更新全局答案。 同一个 dfs 里两者都要算，但用途完全不同 —— 这是本题最容易混的地方。

② 暴力解法与瓶颈

枚举所有节点对 (a, b)，沿路径求和。树上任意两点间有唯一简单路径，可以 O(n²) 暴力，但需要 LCA 或反复爬父指针，代码冗长。

③ 状态定义

dfs(u) 返回：从 u 出发，只往下走（一条链）的最大和，且这条链可以为空（返回 0 表示”不往下走”）。

同时维护一个全局变量 ans，记录”经过 u 的拐弯路径”的最大和。

为什么返回值可以是”空链 = 0”

因为父节点的最优链允许不包含 u 这条分支。如果左子树的最优向下链是负数（例如 -5）， 父节点宁可不要它，所以 Math.max(0, ...) 是必要的。

为什么全局答案要”两边都用”

路径可以”从左子树上来，经过 u，再进右子树”——这是拐弯的，只有在更新 ans 时才允许左右同时用。 往上传值时只能选一边，否则传回父亲的就是一条”分叉链”，不是链了。

  • ans 初值必须是 Integer.MIN_VALUE，不能是 0：当树里所有值都是负数时，答案应是最大的那个单节点（如 [-3] → -3），初值 0 会错误地返回 0。
  • dfs(null) 返回 0（空链）。
  • 顺序：后序。

61. 二叉树的直径（LC 543）

① 题意

二叉树中任意两节点间最长路径的长度。官方明确：长度按边数计（不是节点数）。

官方样例：root = [1,2,3,4,5] → 3（路径 4 → 2 → 1 → 3，共 3 条边）。

① 题意

② 暴力解法与瓶颈

枚举摄像头子集（2^n）逐一检查覆盖，最坏 O(n·2^n)。但注意一个贪心直觉：

64. 二叉树中的最大 BST 子树（LC 333）

① 题意

在二叉树中找出最大的子树（以某节点为根、包含其全部后代）使得该子树是一棵二叉搜索树，返回其节点数。

BST 的判定

一棵子树是 BST ⟺ 它的中序遍历严格递增 ⟺ 对每个节点 u： 左子树所有值 < u.val 且左子树本身是 BST，右子树所有值 > u.val 且右子树本身是 BST。

本题为力扣 Plus 专享

题面需 Plus 会员解锁（无法直接抓取官方样例），下面的验证用例由本笔记独立构造 + 暴力对拍得出。

② 暴力解法与瓶颈

对每个节点 u：判断 u 的整棵子树是否 BST（一次中序遍历 O(n)），是则记 size(u)。 共 n 个节点，最坏 O(n²)。

瓶颈：每个节点的 BST 判定重复做了大量工作 —— 孩子是否 BST、父节点的取值范围，这些信息在自底向上时可以直接传上去。

③ 状态定义

dfs(u) 返回四元组：

位置含义
[0]isBST ? 1 : 0 —— u 的整棵子树是否是 BST
[1]size —— 若是 BST，子树节点数；否则 0
[2]min —— 子树里的最小值（无论是否 BST）
[3]max —— 子树里的最大值（无论是否 BST）

为什么 min/max 在非 BST 时也要算？ 因为非 BST 子树里可能藏着 BST 子树，它的 min/max 对祖先无用，但祖先不能用它来判断范围 —— 所以必须靠 [0] 这个标志位来拒绝它。这就是”返回多值 + 标志位”的典型用法。

同时维护全局 ans：所有节点处发现的合法 BST 子树的最大尺寸。

④ 转移方程推导

记 L = dfs(u.left)、R = dfs(u.right)。u 的子树是 BST 当且仅当四个条件同时成立：

  1. 左子树本身是 BST：L[0] == 1
  2. 右子树本身是 BST：R[0] == 1
  3. 左子树最大值 < u.val：u.left == null || L[3] < u.val
  4. 右子树最小值 > u.val：u.right == null || R[2] > u.val

转移里最容易漏的一步：

ans 的更新 如果只在”返回 BST 子树”时上报，而没有全局 ans，那么当根不是 BST 但内部藏着 一个大 BST 子树时，会返回 0 或错误值。必须像第 60 题那样用全局变量兜底。 典型反例：root = [1] 的左孩子是 [5,2,7] —— 根不是 BST，答案应为 3。

66. 叶值的最小代价生成树（LC 1130）

① 题意

给定正整数数组 arr（2 ≤ arr.length ≤ 40，1 ≤ arr[i] ≤ 15），考虑所有满足以下条件的二叉树：

  • 每个节点有 0 个或 2 个子节点；
  • 数组 arr 的值与树叶节点的值一一对应（按中序遍历顺序）；
  • 每个非叶节点的值 = 其左子树中叶节点的最大值 × 其右子树中叶节点的最大值。

求所有非叶节点值的最小总和。

官方样例：

输入输出
[6,2,4]32
[4,11]44

乘积，不是求和

arr = [4,11] 只有一个可能的树形，其唯一非叶节点值 = 4 × 11 = 44。 如果按”孩子值之和”理解会得到 4 + 11 = 15，与官方答案 44 不符 —— 这题极易被误解成”最优合并 / Huffman”（那是 LC 1135 的问题）。

② 暴力解法与瓶颈

枚举所有满二叉树形状（n 个叶子有 Catalan(n-1) 种）× 所有叶子排列（n!），逐个算代价。 n = 6 时是 42 × 720 = 30240 种，n = 7 时 132 × 5040 ≈ 6.6×10⁵ 种 —— 可以暴力，但显然不是解法。

本页的独立验证

本笔记用上述穷举（枚举全部形状 × 全部排列）对 n = 2…7 做了完整验证， 结论：最优答案恒等于”升序排序后相邻两两乘积之和”，与官方两个样例吻合。验证记录见第 ⑩ 节。

③ 状态定义 / 结论

不需要 DP 状态，直接给结论：

把 arr 升序排序为 a[0] ≤ a[1] ≤ … ≤ a[n-1]，答案 = Σ_{i=1}^{n-1} a[i-1] × a[i]。

对应的树形结构是一条链：a[0] 与 a[1] 挂在同一个父节点下，然后这个父节点再与 a[2] 挂，依次类推。

④ 转移方程推导（为什么是最优）

记某子树叶值的最大值为 mx。把新叶子 x 挂到已有子树（最大 mx）上时：

  • 新增的内部节点值 = mx × x
  • 而 mx 从此变成 max(mx, x)

为了让每一步的 mx × x 尽量小，应该每一步的 x 尽可能小，同时 mx 尽可能小 —— 也就是从小到大依次挂上去。

更严格地看：设最优解的树形被”拉直”成链后，代价不变（n-1 个内部节点），而链上第 i 个挂载的叶值必然对应排序后某个位置；交换论证（把两个相邻的逆序叶值交换，代价不增）可得升序最优。n ≤ 7 的穷举已逐例确认。

链式结构为什么一定不劣

任意满二叉树都可以通过”旋转”（把左子树的根与右子树交换并上提）变成同代价的链式结构， 因为旋转只改变”谁当乘数”，不改变乘积集合。而升序链的每步乘数都是当前最小可达值。

67. 每个元音包含偶数次的最长子字符串（LC 1371）

本题不是树形 DP

它是「位压缩 + 前缀」问题，放在本页是为了对照一个共同主题：状态如何打包成可哈希的量。 第 59/65/68 题把状态打包成 {不选, 选} 沿树上传；本题把状态打包成 5 位奇偶掩码 沿串前缀传递。

① 题意

给定字符串 s（1 ≤ s.length ≤ 5×10⁵，仅小写英文字母），求最长的子串，使得 a、e、i、o、u 在该子串中各出现偶数次（可以是 0 次）。返回长度；不存在则返回 0。

官方样例：

输入输出最长子串
"eleetminicoworoep"13"leetminicowor"（e、i、o 各 2 次，a、u 各 0 次）
"leetcodeisgreat"5"leetc"（2 个 e）
"bcbcbc"6整串（5 个元音各 0 次）

② 暴力解法与瓶颈

枚举所有子串、每次统计 5 个元音的奇偶性：O(n²·5)。瓶颈在于重复统计相同的前缀信息。

③ 状态定义

前缀奇偶掩码 mask[i]：把 s[0..i-1] 里 5 个元音的出现次数对 2 取模，压成一个 5 位二进制数（位 k 表示第 k 个元音出现次数的奇偶性）。

为什么”对 2 取模”就够了

“偶数次”这个约束只关心奇偶性，具体次数完全无用。把2⁵ = 32 种可能压进 5 位是本题的全部关键。

关键性质：子串 s[j..i-1] 中每个元音出现偶数次 ⟺ mask[i] == mask[j]。

推导：子串的计数 = 前缀 i 的计数 − 前缀 j 的计数。两者对 2 取模后要全为 0，即奇偶性相同。✅

④ 转移方程推导

为什么用异或

^ 而不是加法或置位 奇偶性翻转用异或最自然：0^1=1、1^1=0，且满足结合律与自反性（x^x=0）， 这正好对应”出现两次抵消”。若用 |= 就无法表达”翻回 0”。

答案 = max{ (i+1) - first[mask] }，其中 first[m] 是掩码 m 首次出现的前缀长度。

70. 换根 DP — 树中距离之和（LC 834）

① 题意

一棵 n 个节点的无根树（n = 2..10⁴），节点编号 0..n-1，edges[i] = [u, v]。定义 ans[u] 为节点 u 到所有其他节点的距离之和。返回 ans 数组。

官方样例：n = 6，edges = [[0,1],[0,2],[2,3],[2,4],[2,5]] → [8,12,6,10,10,10]。

这是

无根树，必须自己指定一个根 官方输入只给边，不给根。换根 DP 的标准做法是任选 0 为根（或任意节点），先算 ans[0]，再沿边递推。

② 暴力解法与瓶颈

对每个 u 各跑一次 BFS/DFS 求距离和：O(n²)。

瓶颈：相邻两个节点的距离和之间存在 O(1) 的递推关系，一旦发现这个关系就能降到 O(n)。

链形树

n = 10⁴ 的栈溢出风险 Java 默认栈下深度 10⁴ 的递归通常安全，但若 n 增大到 10⁵ 级就必须改迭代。 换根 DP 特别适合改写成迭代形式：第一遍用”显式栈 + 逆序处理”求 size，第二遍用队列正序传播。

换根 DP 的通用套路

凡是”换一个起点 求某个量的值”，且相邻起点之间有 O(1) 递推关系，就用换根 DP：

  1. 任选一个根，用普通 DFS 求出起点的答案；
  2. 推导出”根沿边移动一次”时答案的变化量；
  3. 第二遍 DFS 把答案传给所有邻居。

同一模板的变体见 动态规划索引 里”换根”的延伸。

面试追问：

  • 「改成”到所有点的距离平方和”？」→ 递推式变为 ans[v] = ans[u] + n - 2*size[v] + (2*dist(v,u) + 1)*size[v] - size[v] 一类，需按”距离差 2d+1”重推，链式树用前缀和可解。
  • 「如何在链上做到 O(1) 查询任意两点距离？」→ 前缀和 / 倍增，与换根 DP 同一套”树上前缀”思想。
