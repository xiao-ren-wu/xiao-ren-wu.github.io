1. 爬楼梯（LeetCode 70）

① 题意

楼梯有 n 级台阶，每次可以爬 1 级或 2 级，问爬到第 n 阶共有多少种不同的走法。LeetCode 原题不要求取模（1 ≤ n ≤ 45，答案 f(45) = 1836311903 仍在 int 范围内）。

② 暴力解法与瓶颈

朴素想法是 DFS 枚举每一步走 1 还是走 2：

瓶颈在于重复计算：调用树里 dfs(3) 会被 dfs(4) 和 dfs(5) 各调用一次，dfs(2) 会被调用两次……整个树的节点数是 2^(n/2) 量级。

红色的四个节点是完全相同的问题（参数一样），答案也一样，却算了 4 次。这正是 DP 要解决的问题——把重复子问题的结果记下来复用。

③ 状态定义

dp[i] = 爬到第 i 阶的方法数（“前 i 阶”语义：一维前缀型状态）

为什么用”前 i 个”而不是”以 i 结尾”？ 因为本题的答案本身就是一个”到达某个位置”的计数，不需要在所有 i 中取最优。计数型问题通常用”前 i 个”。

这个状态划分为什么”不重不漏”？ 关键在于选划分依据：

  • 爬到第 i 阶的最后一步只有两种可能，且这两种情况互斥：
    • 最后一步从第 i-1 阶爬 1 级上来
    • 最后一步从第 i-2 阶爬 2 级上来
  • 把所有走法按”最后一步是哪一种”分成两类，不重不漏，这是计数正确性的根本保证。

项结论理由

禁忌

dp[0] 写成 0 是本题最经典的错误 如果 dp[0] = 0，那么 dp[2] = dp[1] + dp[0] = 1，越算越小，最后所有答案都变成 0 或错误值。 判断依据：问自己”凑出 0 需要多少种方案？""站在起点还没开始走，算几种走法？“——答案是 1 种，所以 dp[0]=1。 这个初始化在所有计数型 DP 里都通用（背包的 dp[0]=1、解码方法的 dp[0]=1、矩阵连乘的 dp[i][i]=0 同理，详见 序列 DP）。

面试追问 1：能不能用

BFS 或 数学公式？

  • BFS：可以，按”走了 k 步”分层，状态是 (台阶, 步数)，复杂度 O(n)，但空间大。
  • 数学公式：可以。这是斐波那契数列，通项是 Binet 公式： f(n) = (φ^(n+1) − ψ^(n+1)) / √5，其中 φ = (1+√5)/2，ψ = (1−√5)/2。 面试中能说出”本质是斐波那契，用矩阵快速幂可以做到 O(log n)“是加分项。 但不要用浮点的 Binet 公式写代码——n 稍大就有精度误差。实际写代码仍用迭代或矩阵快速幂（全程整数运算）。

2. 使用最小花费爬楼梯（LeetCode 746）

① 题意

官方原话（照抄题面，别凭记忆改写）

cost[i] 是第 i 个台阶的费用。一旦支付了 cost[i]，你就可以爬 1 级或 2 级。 你可以免费从下标 0 或下标 1 起步。求到达楼梯顶部（下标 cost.length）的最低花费。

① 题意

② 暴力解法与瓶颈

瓶颈：第 i 间偷不偷是个二元决策，n 间房就是 2^n 种组合。而且不同组合在”前 i-1 间偷了多少”上大量重合。

③ 状态定义（本批最重要的范式）

dp[i] = 前 i 间房屋（即 nums[0..i-1]）能偷到的最大金额

“前 i 个”而不是”以 i 结尾”：因为本题是最值问题，答案要在所有 i 里取最大，而”前 i 间”直接就是对 i 的答案，不需要额外的 ans 变量。（对比 最大子数组和，那里必须用”以 i 结尾” + 全局 ans。）

划分依据（对第 i 间做决策）：

“不重不漏”的论证：任意一个合法方案，对第 i 间的态度必然且只能是”偷”或”不偷”之一：

  • 偷 → 因不能偷相邻，第 i-1 间必须放弃 → 剩余问题等价于”前 i-2 间的最优解 + nums[i-1]”
  • 不偷 → 第 i 间没有任何约束 → 剩余问题原封不动就是”前 i-1 间的最优解”

两类互斥且穷尽，所以取 max 即可。这类”选不选型”DP 是本库出现频率最高的 DP 范式（第 42 题”最后一块石头”、第 59 题”打家劫舍 III”、第 68 题”树的最大独立集”全是它的变体）。

破环答案

恒不大于线性答案 破环后每一种情况都是某个子区间的线性解，答案 = max(A, B)。 但线性解是对整条链求最优，可能”首尾都偷”——而这在环上恰恰是非法的。 所以破环是加约束，最优值只会变小或相等，绝不会变大。即 ring ≤ linear。

例子线性解（可偷首尾）破环解（首尾互斥）关系
[1,2,3,1]4（偷 0、2）4（偷 0、2）相等
[2,3,2]4（偷 0、2）3（偷 1）破环更小
[1,2,3,4,5,6,7]1615破环更小
[1,2]22相等
[1,1,2,2,1]43破环更小

规律：ring ≤ linear，且当”线性最优解恰好没有同时偷首尾”时两者相等。 判断技巧：若线性最优解偷了首尾两间，则破环解必然严格更小； 若没偷，则破环解就是线性解。 绝不是 ring ≥ linear。 用 [2,3,2] 自查：线性能偷 1 号和 3 号得 4，环上它们相邻，不能同时偷，所以答案 3。

与第 8 题完全相同：

关键设计决策：把”障碍”编码进状态值为 0，而不是另开一个 blocked[i][j] 数组。原因是：0 个路径数天然表达了”不可达”语义，能让转移方程一行都不改。

④ 转移方程推导

为什么障碍格填 0 就够了，不用特判传播？ 因为下一格会读到这个 0：dp[i][j+1] = dp[i-1][j+1] + dp[i][j]，其中 dp[i][j] = 0 贡献为零，“从障碍物过来”的所有路径被自动过滤掉。这就是”0 作为不可达标记”的优雅之处。

这是”哨兵值”（sentinel value）设计的一个经典应用

在 DP 里选一个语义上无害、但能自动短路错误分支的初始值：

  • 计数 DP 里不可达 → 0
  • 最小值 DP 里不可达 → +∞（见第 10 题）
  • 最大值 DP 里不可达 → -∞

这样转移方程里就不用写 if (可从左边来) 的判断，代码少一半。

B. 自底向上dp[i][j] = 从顶部到 (i,j) 的最小和从上往下（正序）复杂（需处理”只能从上一行 j-1 或 j 来”）

为什么选 A（从下往上）？

  1. 边界天然干净：底部每个位置都是合法终点，无需判断”下方还有没有行”。
  2. 转移只有两个来源且都在下一行：dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])，不涉及越界的负数索引。
  3. 对比方案 B：dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])，在 j=0 时 dp[i-1][-1] 越界，需要额外分支。

规律：当”边界情况复杂”时，尝试换个遍历方向，让边界变成”终点”，通常能大幅简化代码。

也就是说，无论”这个平方数能不能重复用”（正序/逆序），最小值的结果都一样。

  3. 否则：
    • n 是平方数 → 1 个
    • n 能写成 a² + b²（a,b > 0）→ 2 个
    • 否则 → 3 个

时间复杂度 O(√n)。 面试中能提到四平方和定理是明显的加分项。

面试追问 3：为什么本题的

dp[j] 定义”凑出 j 的最少个数”，但第 12 题「单词拆分」dp[i] 是”前 i 个字符”？ 差别在于状态的”结构”：

  • 第 12 题的 s[0..i) 有顺序和重叠（字符会重复），所以状态必须带位置信息
  • 本题的金额是纯容量，j 更大就意味着”更多硬币”，状态只需记容量

判断口诀：如果”用多少”和”用什么”之间有顺序/配对关系，状态要带位置；只是”总量”约束，状态只需带容量。 前者归 序列 DP，后者归 背包问题。
