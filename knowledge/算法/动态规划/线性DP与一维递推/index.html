线性 DP 与一维递推

本页用途

DP 的入门层。状态就是「以 i 结尾」或「前 i 个」，转移是常数个更小状态相加。这一批题量最大、面试命中率最高，但几乎没有难度——真正的门槛不是写出代码，而是养成「先定义状态含义」的习惯。

题号与频率

收录 第 1~15 题，面试命中率 ★★★★★。题目编号沿用 动态规划专项 的全局编号。

与本库已有笔记的关系

本批的 最大子数组和、乘积最大子数组、打家劫舍、单词拆分、解码方法 在本库已有独立的完整笔记，这里只做横向对比和套路提炼，第一次学请直接点进那些笔记。

1. 爬楼梯（LeetCode 70）

题意：每次可以爬 1 或 2 个台阶，爬到第 n 阶有多少种不同方法。

思路：到达第 n 阶，只能从第 n-1 阶走 1 步，或从第 n-2 阶走 2 步。所以 f(n) = f(n-1) + f(n-2)，本质是斐波那契。

代码：

复杂度：时间 O(n)，空间 O(1)。

2. 使用最小花费爬楼梯（LeetCode 746）

题意：cost[i] 是从第 i 阶向上爬需要支付的费用。可以从下标 0 或 1 出发，求到达顶部（第 n 阶）的最小花费。

思路：dp[i] 表示到达第 i 阶的最小花费。注意踩上第 i 阶要付 cost[i]，所以转移是”从哪一阶跳过来 + 付那一阶的钱”。

代码：

复杂度：时间 O(n)，空间 O(1)。

3. 打家劫舍（LeetCode 198）

题意：沿街房屋，不能偷相邻两间，求最大金额。

思路：对第 i 间房做决策：偷 → 只能加上 i-2 的最优解；不偷 → 继承 i-1 的最优解。

复杂度：时间 O(n)，空间 O(1)。

4. 打家劫舍 II（LeetCode 213）

题意：房屋首尾相连成环，仍不能偷相邻两间。

思路：环的问题 → 破环成链。首尾不能同时偷，于是答案 = max(不偷最后一间的最优, 不偷第一间的最优)，即对 [0, n-2] 和 [1, n-1] 各跑一次线性 DP。

代码：

复杂度：时间 O(n)，空间 O(1)。

5. 最大子数组和（LeetCode 53）

本题在本库已有独立笔记

见 最大子数组和，含更完整的图解与关键细节。

题意：求连续子数组的最大和。

思路：dp[i] 表示以 i 结尾的最大子数组和。要么把 i 接到前面（dp[i-1]+nums[i]），要么从 i 重新开始（nums[i]）。答案是所有 dp 的最大值。这是经典的 Kadane 算法。

代码：

复杂度：时间 O(n)，空间 O(1)。

7. 买卖股票的最佳时机（LeetCode 121）

题意：只能买一次、卖一次，求最大利润。

思路：把”在 i 天卖出”作为状态：dp[i] = max(0, dp[i-1] + (prices[i] - prices[i-1]))，另一种等价写法是维护”到目前为止的历史最低价”。

代码：

复杂度：时间 O(n)，空间 O(1)。

8. 不同路径（LeetCode 62）

题意：m×n 网格，从左上角到右下角，只能向右或向下，求路径数。

思路：二维网格 DP，dp[i][j] = dp[i-1][j] + dp[i][j-1]。可以压缩成一维：从左往右扫，dp[j] = dp[j]（来自上方） + dp[j-1]（来自左方）。

代码：

复杂度：时间 O(m·n)，空间 O(n)。

思路：与上题相同，但遇到障碍时 dp[j] = 0（表示该格不可达）。注意第一行的初始化也要考虑障碍。

思路：与路径计数同理，只是把”求和”改成”取最小”。

11. 三角形最小路径和（LeetCode 120）

题意：三角形从上到下的最小路径和，每一步只能移到下一行的相邻位置。

思路：自底向上比自顶向下简单，因为不用处理边界（顶部只有一个入口，底部每个位置都是合法终点）。dp[j] = triangle[i][j] + min(dp[j], dp[j+1])。

代码：

复杂度：时间 O(n²)，空间 O(n)。

12. 单词拆分（LeetCode 139）

本题在本库已有独立笔记

见 单词拆分，含更完整的图解与关键细节。

题意：判断字符串 s 能否由字典中的单词拼接而成（单词可重复使用）。

思路：dp[i] 表示 s 的前 i 个字符能否被拆分。枚举最后一个单词的起点 j，若 dp[j] 为真且 s[j..i) 在字典中，则 dp[i] 为真。属于”完全背包 + 顺序敏感”型 DP。

13. 解码方法（LeetCode 91）

本题在本库已有独立笔记

见 解码方法，含更完整的图解与关键细节。

题意：数字字符串按 A=1…Z=26 解码，求解码方法总数（‘0’ 不能单独解码）。

复杂度：时间 O(n)，空间 O(1)。

14. 零钱兑换（LeetCode 322）

题意：给定硬币面额（每种无限个），凑出 amount 所需的最少硬币数，凑不出返回 -1。

复杂度：时间 O(amount × k)，空间 O(amount)。

思路：把 1、4、9… 看作”面额为平方数的硬币”，就完全等价于第 14 题。

关键结论与面试要点

通用套路：① 定义状态含义（“以 i 结尾”还是”前 i 个”）→ ② 写出转移方程 → ③ 确定遍历顺序（正序/逆序/由外到内）→ ④ 边界初始化 → ⑤ 空间压缩。
