字符串索引

本页用途

字符串题看起来千奇百怪，其实只有三类：

  1. 找子串（最长回文子串 的中心扩展、最短回文串 的 KMP）
  2. 按规则变换/构造（Z 字形变换 的模拟、有效数字 的扫描）
  3. 复用经典结构（最短回文串 把问题转成”最长回文前缀”，就是 KMP 的变形）

本主题 4 篇，难点全在转化而不是实现。有效数字 是唯一一篇纯考状态机的。

读完本页你应该能自己回答：中心扩展为什么只需要 O(n²) 而不是 O(n³)；最短回文串 怎么把”加字符成回文”转成”最长回文前缀”；有效数字 的状态为什么可以压到几个布尔量。

最短回文串问题转成”最长回文前缀”，KMP 前缀函数表读出转化 + KMP，本主题最值得读的一篇

关键结论

一、中心扩展：奇偶两种中心，O(n²) 但足够

最长回文子串 不需要 DP，两层循环就够了：

中心类型例子起始调用
奇数长度"aba"expand(i, i)
偶数长度"abba"expand(i, i+1)

偶数中心不能漏

只写expand(i, i) 会漏掉所有偶数长度的回文（"abba" 这类），是本题最高频的 bug。两句都要写。

为什么中心扩展比 DP 更该会

DP 版是 O(n²) 空间，中心扩展是 O(1) 空间，代码还更短。面试里先说中心扩展，DP 只在追问”能不能更快”时提（如 Manacher 算法）。见该篇的核心思想一节。

二、问题转化：把”补字符”变成”找最长回文前缀”

最短回文串 要求在 s 前面加字符使它成为回文。原题看着要做很多次尝试，但可以转化：

能在前面加字符得到回文 ⟺ s 中存在一个回文前缀。要找的最小长度 = n − 最长回文前缀长度。

而”最长回文前缀”用 KMP 求解：

为什么用 '#' 分隔作用
让 s 和 reverse(s) 的匹配不能跨界保证匹配长度 ≤ n，否则 pi 会被两段串的跨界重复撑大
'#' 是唯一字符不会和 s 里的任何字符冲突

这个转化的价值

“求 s 的最长回文前缀”是一个标准的 KMP 问法，面试官看到这步转化会觉得你抓住了题目的本质。比”试每个切点、检查回文”的 O(n²) 写法高一个档次。见该篇的核心思想一节。

三、模拟题：按行号写入，不做二维数组

Z 字形变换 直接构造二维数组再读出来是可行的，但更省的做法是只维护”当前写到第几行”：

关键点说明
方向变量 dir只在撞到边界时翻转，不要在每个字符都判断
单行特判numRows == 1 时直接返回原串，否则会越界

禁忌

numRows == 1 的特判 上面那段代码里 row == numRows - 1 在 numRows == 1 时恒成立，会一直 dir = -1 让 row 变负。必须提前返回。见该篇的关键细节一节。

四、状态机：有限状态 + 字符集校验

有效数字 判断字符串是否是合法数字（如 "+3.5e-10"）。这类题的通用解法是状态机：

阶段允许的字符转移条件
起始+ - 或 数字处理符号后必须接数字
整数部分0-9记录是否见过数字
小数点.只能出现一次，且前面必须已有数字
小数部分0-9同上
指数标记e E只能出现一次，前面必须已有数字
指数符号+ -最多一次
指数部分0-9结束时必须至少有一个

状态机的三件套

  1. 状态变量：目前处于哪个阶段、关键标志位（见小数点 / 见 e / 见数字）
  2. 字符集：每个阶段允许哪些字符
  3. 终态检查：结束时必须满足”见过数字”且不在半途（不能在 . 或 e 之后结束）

有效数字 的代码把这三样都写全了，是有限状态机题的标准范本。见该篇的核心思想一节。

为什么不用正则

正则^[-+]?[0-9]*\.?[0-9]+([eE][-+]?[0-9]+)?$ 也能写，但面试里默写正则几乎没有一次能一次写对，而且写不出状态转移的推理过程。用状态机既能保证正确，又能展示推理能力。
