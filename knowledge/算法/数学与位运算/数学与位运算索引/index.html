数学与位运算索引

本页用途

这一类题不考算法，考推导。它们的共同点是：数据结构都可以不用，答案藏在数学结构里——按位统计、构造回文、质因数分解、字典序前缀计数。 本主题 5 篇难度全部是 HARD（除了整数反转），因为难度不在代码，在想出那个计数公式。这也是本库最”反直觉”的一块：读懂代码只要十分钟，讲明白推导要一小时。

读完本页你应该能自己回答：数字 1 的个数 的按位统计是怎么分段的；为什么 超级回文数 只需要枚举约 10^5 个回文根；数组的最大公因数排序 为什么能用并查集；最大为 N 的数字组合 为什么要按位数拆成两部分。

本篇笔记

笔记核心解法什么时候读
整数反转循环 pop 每一位并累加，用 long 提前判溢出最简单的数位题，先熟悉”逐位处理”
数字 1 的个数按位统计，分高位 / 当前位 / 低位三段讨论本库最经典的数位 DP / 计数题
最大为 N 的数字组合按位数拆两部分：位数 < n 累乘，位数 = n 逐位比较计数题的”分段累加”思路
超级回文数枚举回文根构造回文数，只检查约 10^5 个构造 + 剪枝，利用对称性
数组的最大公因数排序质因数集合 + 并查集连通，DFS 出序本主题最难，涉及建模转换

你要搞清的问题去哪一篇的哪一节

为什么溢出判断要提前整数反转
计数题怎么拆成”能算的部分”最大为 N 的数字组合

关系型约束怎么变成图数组的最大公因数排序

关键结论

一、数位题的核心是”按位贡献”而不是枚举

数字 1 的个数 求 1..n 里数字 1 的总出现次数。逐个数枚举是 O(n log n)，但按位统计可以做到 O(log n)：

对每一位 p（个位 1、十位 10、百位 100…），把 1..n 按”在 p 位上是否为 1”分组，贡献可以闭式求出：

段落范围贡献
高位部分n / (p*10) 个完整循环每循环贡献 p 个 1
当前位cur = (n / p) % 10cur == 1 时贡献 p；cur > 1 时贡献 p；cur == 0 时贡献 0
低位部分n % p影响是否凑满当前位

当前位要分三种情况，不能合并

cur == 0（这 p 位上还没有数到 1）、cur == 1（刚好进位，贡献是 low+1）、cur > 1（已经跑完一整段，贡献满 p）。三种情况公式不同，合并会算错。见该篇的核心思想一节。

二、整数反转：溢出的判断要”提前”

整数反转 本身算法很简单（逐位 pop 累加），但它有一个必考的细节——怎么判断会溢出：

做法问题
先算后判Java 里 int 溢出会绕回，事后无法判断
乘法前判res > MAX/10 必然溢出；res == MAX/10 时要看末位

面试时主动说

“我用 long 接住结果，同时在每次×10 之前判断是否会越界。“这句话能直接把这题从”会写”提到”写对了”。见该篇的关键细节一节。

三、计数题：拆成「能直接算」和「需要逐位比」两部分

最大为 N 的数字组合 统计用给定数字集合能拼出多少个 ≤ n 的不同整数（不含前导零）。通用做法是按位数拆开：

为什么要按位数拆

位数比 n 少的数一定小于 n，不用比；位数和 n 一样的数才需要逐位比大小。把”需要比较”的部分限制在最小的那一类，是计数题的通用降复杂度手法。同样的思路见 数字 1 的个数（按位拆段）。

四、利用对称性做构造 + 剪枝

超级回文数 要求统计 n 和 2n 拼接后是回文的数（n ≤ 10^18）。直接枚举 n 是 10^18 次，不可能。剪枝思路来自回文的对称性：

关键剪枝：只留首尾为 8/9 的

2n 的首尾由 n 决定。n 的首尾只有 8 或 9 时，2n 拼接才可能形成回文（因为要”n + 2n 反转”恰好对称）。这一条把枚举量又砍掉一个量级。见该篇的关键细节一节。

五、关系型约束转成图：并查集

数组的最大公因数排序 要求：若两个数 gcd > 1 就把 a 放在 b 前面，否则任意。核心是把”关系”变成”图”：

步骤为什么
拆成质因子（而非两两求 gcd）两两求 gcd 是 O(n²)，拆成质因子后每个数只和它的质因子有关
用并查集而非显式建图只需要”连通性”，不需要完整的邻接表
DFS 后序反转得到答案要保证”先访问 a 的约束 b 就先被输出”（拓扑序的逆序）

为什么是后序的逆序

题目要求”a 的 gcd>b 就是 a 在前”，而 DFS 的后序天然给出”被依赖的先输出”。取后序的逆序就得到依赖者在前。见该篇的核心思想一节。
