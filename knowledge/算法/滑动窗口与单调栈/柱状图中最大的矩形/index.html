柱状图中最大的矩形

题目信息

LeetCode 84 · 困难 · 通过率 49.1% · 高频 34.8 标签：栈 / 数组 / 单调栈 题目链接：https://leetcode.cn/problems/largest-rectangle-in-histogram/

一句话结论

核心解法：维护单调递增栈，栈顶出栈时结算以该柱子为最矮、能向左右扩展到的最大矩形。 复杂度：时间 O(n)，每个元素最多入栈和出栈一次，空间 O(n)，栈空间。

一、题目描述

给定 n 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

示例 2：

提示：

  • 1 <= heights.length <= 10^5
  • 0 <= heights[i] <= 10^4

二、解题思路

2.1 核心思想

对于每个柱子的高度 h，它能形成的最大矩形是：以 h 为高，向左右扩展到第一个比它矮的柱子为止。

关键问题：如何快速找到每个柱子左右第一个更矮的柱子？

2.2 解法：单调递增栈

维护一个单调递增的栈（存放索引），遍历每个柱子：

  1. 当当前柱子高度 >= 栈顶柱子高度 → 入栈
  2. 当当前柱子高度 < 栈顶柱子高度 → 弹栈，计算以弹出高度为高的矩形面积
    • 宽度 = 当前索引 - 新栈顶索引 - 1
    • 弹出柱子的右边界 = 当前柱子，左边界 = 栈中下一个元素

三、复杂度

  • 时间复杂度：O(n)，每个元素最多入栈和出栈一次
  • 空间复杂度：O(n)，栈空间

五、关键细节与常见错误

注意点说明
哨兵 -1栈底始终保留 -1，方便计算左边界（左边没有更矮时宽度延伸到开头）
宽度 = i - peek - 1弹出高度的右边界是 i，左边界是新的栈顶（下一个更矮的柱子）
等于的情况不弹栈高度相等时弹栈或不弹栈结果都对，但等高的柱子会重复计算
结束后清空栈遍历完后栈中剩下的柱子右边都延伸到数组末尾
