# 不同的子序列 II

## 题目描述

给定一个字符串 `s`，计算 `s` 的 **不同非空子序列** 的个数。因为结果可能很大，所以返回答案需要对 `10^9 + 7` 取模。

字符串的 **子序列** 是经由原字符串删除一些（也可能不删除）字符而不改变剩余字符相对位置形成的新字符串。

例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是。

**示例 1：**

```
输入：s = "abc"
输出：7
解释：7 个不同的子序列分别为 "a", "b", "c", "ab", "ac", "bc", "abc"。
```

**示例 2：**

```
输入：s = "aba"
输出：6
解释：6 个不同的子序列分别为 "a", "b", "ab", "aa", "ba", "aba"。
注意 "aba" 的子序列中不能有重复的，例如 "a" 只算一次。
```

**示例 3：**

```
输入：s = "aaa"
输出：3
解释：3 个不同的子序列分别为 "a", "aa", "aaa"。
```

**提示：**

- `1 <= s.length <= 2000`
- `s` 仅由小写英文字母组成

## 解题思路

### 核心思想：DP 去重

#### 基本递推

如果不考虑重复，所有子序列（包括空）的数量是：
```
dp[i] = 2 × dp[i-1]
```
因为对于前 i-1 个字符的每个子序列，我们都可以选择添加或不添加 s[i-1]。

#### 去重

重复的来源：如果某个字符 `c` 在前面出现过，那么 `c + (前面字符的子序列)` 会和之前的某一部分重复。

具体来说，`last[c]` 表示字符 `c` 上一次出现时的 dp 值（即当时已有的子序列数量）。当再次遇到相同的 `c` 时，这些子序列已经通过上一次的 `c` 生成过了，所以要减去。

```
dp[i] = 2 × dp[i-1] - last[c]

其中 last[c] 是字符 c 上次出现时的 dp[i-1] 值（在加入 c 之前已有的子序列数量）。
```

### 算法步骤

```
dp[0] = 1（空子序列）
last 数组初始化为 0

for i in [1, n]:
  c = s[i-1]
  dp[i] = 2 * dp[i-1] - last[c]
  更新 last[c] = dp[i-1]

返回 dp[n] - 1（去掉空子序列）
```

### 图解示例

```
s = "aba"

初始化：dp[0]=1, last[a]=last[b]=0

i=1, c='a':
  dp[1] = 2*1 - 0 = 2  → {空, "a"}
  last['a'] = 1
  子序列："" , "a"

i=2, c='b':
  dp[2] = 2*2 - 0 = 4  → {空, a, b, ab}
  last['b'] = 2
  子序列："", "a", "b", "ab"

i=3, c='a':
  预期 2*4 = 8，但减去重复的 last['a']=1
  dp[3] = 2*4 - 1 = 7  → {空, a, b, ab, aa, ba, aba}
  重复的 1 个是 "a"（由第一个 'a' 生成的和由第二个 'a' 生成的是同一个）
  last['a'] = 4

结果 = dp[3] - 1 = 6 ✓
```

### 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n) 或 O(1)（滚动变量 + 固定 26 大小数组）

## 代码

```java
class Solution {
    public int distinctSubseqII(String s) {
        int MOD = 1_000_000_007;
        int n = s.length();
        int[] dp = new int[n + 1];
        int[] last = new int[26];

        dp[0] = 1;

        for (int i = 1; i <= n; i++) {
            int c = s.charAt(i - 1) - 'a';
            dp[i] = (dp[i - 1] * 2) % MOD;
            dp[i] = (dp[i] - last[c] + MOD) % MOD;
            last[c] = dp[i - 1];
        }

        return (dp[n] - 1 + MOD) % MOD;
    }
}
```

## 关键细节/常见错误

| 注意点 | 说明 |
|--------|------|
| `last[c]` 存储的是 dp[i-1] | 不是 dp[i]，而是该字符出现前的 dp 值，因为减的是上轮新增的 |
| 取模时减法的处理 | `(dp[i] - last[c] + MOD) % MOD` 防止负数 |
| 最后减 1 也要 +MOD | `(dp[n] - 1 + MOD) % MOD` 去掉空子序列 |
| last 数组大小为 26 | 小写英文字母，每个字母只需要记住上次出现的 dp 值 |
| 滚动变量优化 | 实际上只需要 dp[i-1] 和 dp[i]，可以用两个 long 变量替代数组 |
