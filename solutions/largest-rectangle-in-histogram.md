# 柱状图中最大的矩形

## 题目描述

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

**示例 1：**

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形是高度为 5 和 6 的柱子形成的 5×2 矩形，面积 10。
```

**示例 2：**

```
输入：heights = [2,4]
输出：4
```

**提示：**

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

## 解题思路

### 核心思想

对于每个柱子的高度 `h`，它能形成的最大矩形是：以 `h` 为高，向左右扩展到第一个比它矮的柱子为止。

关键问题：如何快速找到每个柱子左右第一个更矮的柱子？

### 解法：单调递增栈

维护一个**单调递增**的栈（存放索引），遍历每个柱子：

1. 当当前柱子高度 `>=` 栈顶柱子高度 → 入栈
2. 当当前柱子高度 `<` 栈顶柱子高度 → 弹栈，计算以弹出高度为高的矩形面积
   - 宽度 = 当前索引 - 新栈顶索引 - 1
   - 弹出柱子的右边界 = 当前柱子，左边界 = 栈中下一个元素

### 图解示例

```
heights = [2,1,5,6,2,3]

栈（索引）：
[0]         → 2 入栈
[]          → 1 < 2，弹栈0，面积=2*1=2，当前1入栈
[1]
[1,2]       → 5 > 1，入栈
[1,2,3]     → 6 > 5，入栈
[1]         → 2 < 6，弹栈3，面积=6*1=6
            → 2 < 5，弹栈2，面积=5*2=10 ← 最大
[1,4]       → 2 > 1，入栈
[1,4,5]     → 3 > 2，入栈
结束后弹栈处理剩余：
弹栈5，面积=3*1=3
弹栈4，面积=2*4=8
弹栈1，面积=1*6=6

最大面积 = 10
```

### 复杂度分析

- **时间复杂度**：O(n)，每个元素最多入栈和出栈一次
- **空间复杂度**：O(n)，栈空间

## 代码

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1); // 哨兵，方便计算左边界
        int maxArea = 0;

        for (int i = 0; i < heights.length; i++) {
            while (stack.peek() != -1 && heights[i] < heights[stack.peek()]) {
                int h = heights[stack.pop()];
                int w = i - stack.peek() - 1;
                maxArea = Math.max(maxArea, h * w);
            }
            stack.push(i);
        }

        while (stack.peek() != -1) {
            int h = heights[stack.pop()];
            int w = heights.length - stack.peek() - 1;
            maxArea = Math.max(maxArea, h * w);
        }

        return maxArea;
    }
}
```

## 关键细节/常见错误

| 注意点 | 说明 |
|--------|------|
| 哨兵 `-1` | 栈底始终保留 -1，方便计算左边界（左边没有更矮时宽度延伸到开头） |
| 宽度 = i - peek - 1 | 弹出高度的右边界是 i，左边界是新的栈顶（下一个更矮的柱子） |
| 等于的情况不弹栈 | 高度相等时弹栈或不弹栈结果都对，但等高的柱子会重复计算 |
| 结束后清空栈 | 遍历完后栈中剩下的柱子右边都延伸到数组末尾 |
