# 数字 1 的个数

## 题目描述

给定一个整数 `n`，计算所有小于等于 `n` 的非负整数中数字 `1` 出现的个数。

**示例 1：**

```
输入：n = 13
输出：6
解释：1（1次）、10（1次）、11（2次）、12（1次）、13（1次），共 6 次
```

**示例 2：**

```
输入：n = 0
输出：0
```

**提示：**

- `0 <= n <= 10^9`

## 解题思路

### 核心思想：逐位统计

要统计 1 到 n 中所有数字 1 出现的总次数，可以分别统计每一位（个位、十位、百位...）上出现 1 的次数，然后求和。

对于第 `k` 位（`factor = 10^k`），将 n 分成三部分：

```
高位部分 = n / (factor * 10)
当前位   = (n / factor) % 10
低位部分 = n % factor
```

当前位 digit 有三种情况：

| 情况 | 该位贡献的 1 的次数 | 示例（n=213, 十位） |
|------|-------------------|-------------------|
| digit == 0 | `high * factor` | 十位=1，high=2 → 2×10=20 |
| digit == 1 | `high * factor + low + 1` | 十位=1 → 2×10+3+1=24 |
| digit > 1 | `(high + 1) * factor` | 十位=3 → (2+1)×10=30 |

### 图解示例

```
n = 213，统计十位（factor=10）上 1 的次数：

n = 2 1 3
     ↑
  十位 digit=1

high = 213 / (10*10) = 2
low  = 213 % 10 = 3
digit = (213 / 10) % 10 = 1

该位贡献 = high * 10 + low + 1 = 2*10 + 3 + 1 = 24

含义：十位为 1 的数有：
  10-19（high=0）: 10个数
  110-119（high=1）: 10个数
  210-213（high=2）: 低3位从0到3，4个数（210,211,212,213）
  合计 = 10 + 10 + 4 = 24
```

```
n = 213，统计百位（factor=100）上 1 的次数：

digit = (213/100) % 10 = 2 > 1
贡献 = (2+1) × 100 = 300

含义：百位为 1 的数有 100-199，共 100 个。
```

### 复杂度分析

- **时间复杂度**：O(log n)，n 的位数
- **空间复杂度**：O(1)

## 代码

```java
class Solution {
    public int countDigitOne(int n) {
        int count = 0;
        long factor = 1;

        while (factor <= n) {
            long high = n / (factor * 10);
            long digit = (n / factor) % 10;
            long low = n % factor;

            if (digit == 0) {
                count += high * factor;
            } else if (digit == 1) {
                count += high * factor + low + 1;
            } else {
                count += (high + 1) * factor;
            }

            factor *= 10;
        }

        return count;
    }
}
```

## 关键细节/常见错误

| 注意点 | 说明 |
|--------|------|
| factor 用 long 防止溢出 | 当 n 接近 10^9 时，factor×10 可能超出 int 范围 |
| digit=1 时加 `low + 1` | low 从 0 开始计数，所以还要 +1（代表 low=0 的情况） |
| digit=0 时没有额外的 +1 | 比如十位为 0，不会出现 "当前位放 1" 的情况 |
| 高位部分可能为 0 | n=9，十位 high=9/(100)=0，十位没有 1 出现 |
| 统计的是所有位的总和 | 不是某个范围内的数字个数，而是所有数字中 1 出现的总次数 |
