# 滑动窗口最大值

## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

**示例 1：**

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
窗口位置                   最大值
---------------           -----
[1  3  -1] -3  5  3  6  7   3
 1 [3  -1  -3] 5  3  6  7   3
 1  3 [-1  -3  5] 3  6  7   5
 1  3  -1 [-3  5  3] 6  7   5
 1  3  -1  -3 [5  3  6] 7   6
 1  3  -1  -3  5 [3  6  7]  7
```

**示例 2：**

```
输入：nums = [1], k = 1
输出：[1]
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 解题思路

### 核心思想：单调队列（双端队列）

维护一个双端队列（deque），其中**存储的是索引**，且队列中索引对应的值是**单调递减**的。

这样队首始终是当前窗口最大值的索引。

### 算法步骤

```
遍历数组：
  1. 移除队首中超出窗口范围的索引（index < i-k+1）
  2. 移除队尾中所有值 ≤ nums[i] 的索引（保持单调递减）
  3. 将当前索引入队
  4. 当 i >= k-1 时，队首索引对应的值就是当前窗口的最大值
```

### 图解示例

```
nums = [1,3,-1,-3,5,3,6,7], k=3

i=0, num=1: deque=[0]             窗口未形成
i=1, num=3: deque=[1]             ← 移除队尾的 0（3>1）
i=2, num=-1: deque=[1,2]          窗口 [1,3,-1] → max=3
i=3, num=-3: deque=[1,2,3]        窗口 [3,-1,-3] → max=3（1 已过期）
i=4, num=5: deque=[4]             ← 移除所有小于5的索引
                                   窗口 [-1,-3,5] → max=5
i=5, num=3: deque=[4,5]           窗口 [-3,5,3] → max=5
i=6, num=6: deque=[6]             ← 移除所有小于6的索引
                                   窗口 [5,3,6] → max=6
i=7, num=7: deque=[7]             ← 移除所有小于7的索引
                                   窗口 [3,6,7] → max=7

输出：[3,3,5,5,6,7]
```

### 复杂度分析

- **时间复杂度**：O(n)，每个元素入队和出队最多一次
- **空间复杂度**：O(k)，队列最多存储 k 个元素

## 代码

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums.length == 0 || k == 0) return new int[0];

        int n = nums.length;
        int[] result = new int[n - k + 1];
        Deque<Integer> deque = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            while (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
                deque.pollFirst();
            }

            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
                deque.pollLast();
            }

            deque.offerLast(i);

            if (i >= k - 1) {
                result[i - k + 1] = nums[deque.peekFirst()];
            }
        }

        return result;
    }
}
```

## 关键细节/常见错误

| 注意点 | 说明 |
|--------|------|
| 队列存索引而非值 | 通过索引可以判断是否超出窗口范围，也能获取实际值 |
| 用 `<=` 移除队尾 | 等于时也移除，因为新元素下标更大、生命周期更长，留旧的没意义 |
| 先清理过期再清理队列 | 顺序重要：先移除窗口外的，再调整单调性 |
| k=1 的情况 | 每个元素都是窗口最大值，直接返回原数组 |
| 结果数组长度 | `n - k + 1`，当 k=n 时长度为 1 |
