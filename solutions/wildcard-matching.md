# 通配符匹配

## 题目描述

给你一个输入字符串 `s` 和一个字符模式 `p`，请你实现一个支持 `'?'` 和 `'*'` 通配符的模式匹配：

- `'?'` 可以匹配任何单个字符
- `'*'` 可以匹配任意字符串（包括空字符串）

要求判定字符串 `s` 和模式 `p` 是否完全匹配。

**示例 1：**

```
输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa"。
```

**示例 2：**

```
输入：s = "aa", p = "*"
输出：true
解释：'*' 可以匹配任意字符串。
```

**示例 3：**

```
输入：s = "cb", p = "?a"
输出：false
解释：'?' 匹配 'c'，但第二个字符 'a' 无法匹配 'b'。
```

**示例 4：**

```
输入：s = "adceb", p = "*a*b"
输出：true
```

**示例 5：**

```
输入：s = "acdcb", p = "a*c?b"
输出：false
```

**提示：**

- `0 <= s.length, p.length <= 2000`
- `s` 仅由小写英文字母组成
- `p` 仅由小写英文字母、`'?'` 和 `'*'` 组成

## 解题思路

### 解法：动态规划 O(mn)

#### 状态定义

`dp[i][j]` 表示 `s[0..i-1]` 与 `p[0..j-1]` 是否匹配。

#### 状态转移

1. **`p[j-1]` 是普通字符**：`dp[i][j] = dp[i-1][j-1] && s[i-1] == p[j-1]`
2. **`p[j-1]` 是 `'?'`**：`dp[i][j] = dp[i-1][j-1]`（匹配一个字符）
3. **`p[j-1]` 是 `'*'`**：
   - 匹配空串：`dp[i][j-1]`
   - 匹配一个或多个字符：`dp[i-1][j]`
   - 综上：`dp[i][j] = dp[i][j-1] || dp[i-1][j]`

#### 初始化

- `dp[0][0] = true`（空串匹配空模式）
- `dp[0][j] = dp[0][j-1] && p[j-1] == '*'`（空串只能匹配全是 `*` 的模式）

### 图解示例

### 复杂度分析

- **时间复杂度**：O(mn)，其中 m 和 n 分别是 s 和 p 的长度
- **空间复杂度**：O(mn)，可优化为 O(n) 的滚动数组

## 代码

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length(), n = p.length();
        boolean[][] dp = new boolean[m + 1][n + 1];

        dp[0][0] = true;
        for (int j = 1; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 1];
            }
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                char sc = s.charAt(i - 1);
                char pc = p.charAt(j - 1);

                if (pc == '*') {
                    dp[i][j] = dp[i][j - 1] || dp[i - 1][j];
                } else if (pc == '?' || sc == pc) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
            }
        }

        return dp[m][n];
    }
}
```

## 关键细节/常见错误

| 注意点 | 说明 |
|--------|------|
| `*` 匹配空串用 `dp[i][j-1]` | 表示忽略当前 `*`，用模式的前面部分继续匹配 |
| `*` 匹配多字符用 `dp[i-1][j]` | 表示 `*` 已匹配了 s 中的一个字符，保留 `*` 继续匹配后续 |
| 初始化的 `dp[0][j]` | 只有连续开头的 `*` 才能匹配空串，一旦遇到非 `*` 字符就停止 |
| `?` 必须匹配一个字符 | 所以 `dp[i][j]` 依赖 `dp[i-1][j-1]`，不能为空 |
